# EMG Hand V1 - Research & Training Notebooks

This directory is reserved for Jupyter and Colab training notebooks.

- The V1 1D CNN model was trained using the cross-subject split defined in `results/subject_split.json`.
- Training history and curves are documented in `results/training_history.csv` and `results/confusion_matrix.png`.
- Standalone verification can be executed via `python3 scripts/evaluate_v1.py`.
